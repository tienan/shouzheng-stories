# 守正异闻录

《明治未明》的中文小说阅读站，适配 GitHub Pages。

## 本地预览

需要 Python 3.10 或更新版本，无第三方依赖。

```sh
python build.py
python check.py
python -m http.server 8765 --directory docs --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765`。

## 更新小说

1. 修改 `content/meiji/` 下的 Markdown 正文。
2. 新增章节时，在 `site.json` 的 `book.chapters` 中添加节次、标题、文件路径和一句话简介。`id` 使用唯一的短名，例如 `02`。
3. 执行 `python build.py` 和 `python check.py`，检查生成的网页后提交并推送。

每个 Markdown 文件开头可以保留作品标题与章节标题。正文支持段落、二至四级小标题、分隔线、引用、简单列表、粗体及链接。目录、章节导航、阅读字数、RSS 和站点地图从同一份章节清单生成。

## GitHub Pages

发布源使用 `main` 分支下的 `/docs` 文件夹，网页已包含 `.nojekyll`。GitHub Pages 的公开网址写在 `site.json` 的 `url` 字段；更换仓库名或绑定域名后，修改它并重新生成。

`docs/` 是生成文件，更新正文后应连同它一起提交。GitHub 的公开仓库只收录本站所需的小说、插画与网页源文件，不包含本地写作记录、平台处理记录或旧稿归档。

## 阅读功能

- 手机与桌面排版。
- 日间、夜间、暖纸三种主题。
- 字号与正文宽度调整。
- 本机阅读位置记录与首页继续阅读入口。
- 完整章节目录、前后节导航及 RSS。

阅读设置与进度保存在读者浏览器中，不收集账号或邮件地址。
