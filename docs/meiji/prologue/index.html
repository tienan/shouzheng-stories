三十二岁的守正，在一家制造企业管着一个车间。

一个雨天等车时，他在旧书摊随手翻到一本小手册。巴掌大小，红色封皮磨得发白，纸页泛黄。他买回住处，断断续续看了些，偶尔在页边画一个问号。

有几页讲事情该怎样查清，又该和什么人一道做。他看得入神，轮到自己写停工情况说明，却把采购部经理的名字添上，又划掉。那份说明改了三遍，仍没有写完。

再睁眼时，那份说明已经不见了。

门外有人称他“陛下”。

1867年，京都御所。他成了少年天皇睦仁。

幕府还在，诸藩各有兵马。有人奔走着请求天皇发下一道诏书，也有人守在宫门外，打听谁见过天皇，天皇说了什么。

守正知道日本后来会走向怎样的战争。可眼前这个国家的朝廷、藩政和人情，他几乎一无所知。

他先遇到一个送炭的孩子。

孩子挨了打，家里的炭钱却迟迟拿不到。守正追问几句，才发现，要替人讨一笔钱，远没有他想的那么简单。

他又吩咐侍从：明日，把孩子叫来。

口谕走过几道回廊，送回来时，已经换了一个意思。

于是，他取来纸笔，亲手写下召见的命令。

这一回，他坐在炭火旁，听着脚步渐渐远去。

到了转角，脚步停了。
