第二节　回话

约 2,808 字 · 阅读约 8 分钟

阅读设置

回来的不止青木一个人。

纸门拉开，一名鬓角发白的侍从跟在他身后。那张墨迹未干的纸，已经到了来人手里。

“藤井。”青木跪下，声音有些紧，“方才接纸的是藤井。”

他记着守正的吩咐，先报了名字。

藤井将纸托在身前，俯下身。

纸的一角翘起，他用指腹轻轻压平，避开了那团未干的墨。

“陛下亲笔，不宜就这样拿到炭商家中。臣斗胆，先请青木回来。”

“字写错了？”

“字没有错。”

“那是哪里不宜？”

藤井抬起一点头。

“今日是召人。到了外头，这张纸却未必只作召人用。有人拿它讨钱，有人拿它向别家借钱，再有人问起，便只说是御前给的。”

守正看向那团洇开的墨。

他方才写字时，只想着别再传错，没想过这张纸离开自己之后，还能被拿去做些什么。

“怎样才能把人叫来？”

“另纸照录，交代门上，再去传话。原纸请留在这里。”

“上回为什么改成森田来问？”

藤井的手微微收紧。

“是臣的意思。”

青木伏下的肩膀动了一下。

“陛下每日要见的人多。炭商家的事，让经手的人问妥了，再来回禀，省得御前劳神。”

“森田的话，我已经听过了。”

守正把纸往前推了推。

“清吉的话还没有说完。”

藤井没有接话。

炭火里响了一声轻爆。守正这才发觉，自己又在等对方立刻点头了。他把手放回膝上，停了片刻。

“你照抄一张，念给我听。”

藤井取来纸笔，写得比他快，也比他稳。

藤井逐句念过。守正听清了“清吉本人”和“携旧账”，这才让青木接过抄件。青木起身前，藤井忽然叫住了他。

“记下交给了谁。传到没有，回来说明白。”

这一回，两个人走出去的脚步没有在转角停留。

午前，青木回来了。

“已交给门上的人。”

守正放下筷子，筷尖磕在碗沿，响了一声。青木的目光跟着一颤，他才将两根筷子慢慢摆齐。

“清吉知道了？”

青木愣了一下。

“门上的人说，即刻就去。”

守正望了望纸门。外面阳光已经照上廊柱，早晨那片昏暗不见了。

他很想说，那就再去问。

话到了嘴边，又停住。青木才十七八岁，进出宫门究竟要经过谁，他根本没有问过。自己一句一句追着要结果，跑腿的人便只能一趟一趟地跑。

“你自己能出去吗？”

“须另行报知。”

“要多久？”

“臣……不敢说。”

“那就请门上回来的人带句话。交到了谁手里，对方怎么答的，我想听这个。”

青木应声退下。

到了午后，回话终于到了。

清吉出门了，接话的是他母亲。她说知道了，明早让孩子带账来。

“还说什么？”

青木想了想。

“问了几时能回去。”

“怎么答的？”

“说御前问完，自会让他回去。”

门上的人把抄件带了回来。藤井在纸下记了回话，守正点过头，将它与亲笔纸条一同放到案边。

总算传到了。

傍晚，森田送来宫里记的炭账。薄薄几页，边上挤着小字，还有些勾画。守正翻过两遍，只辨出几处数字，弄不明白哪些是送来的，哪些是已经支给的。

森田俯身，指着其中几行解释。

守正听了一会儿，让他从第一笔重新说。

第三次讲到“尚未支下”时，森田的声音已经有些哑了。

“先放在这里。”守正说，“明日拿清吉家的来对。”

森田看了一眼案边折起的纸，没有再说什么。

那晚，守正很晚才睡着。

他想起自己的手机。手顺着身侧摸了一下，碰到的只有层叠的衣料。倘若手机还在，打一个电话，问对方有没有收到消息，不过半分钟的事。

可这里要等人走到门上，走出宫门，穿过街巷，再原路回来。

他甚至不知道那条街离这里有多远。

第二天，清吉来了。

仍是昨天那件短衣。指背上的红痕已经结了一层薄痂，怀里抱着一个旧布包。

他被领到廊下，膝盖刚弯，守正便指了指背风处。

“去那边。”

藤井将垫子移了过去。

清吉坐得很拘谨，两只手始终压着布包。

守正叫青木端来热水，等他喝过一口，才问父亲怎样。

“夜里还咳，今早能坐起来了。”

“昨日的钱，拿到了？”

“拿到了。母亲让小人谢过陛下，也谢过中山大人。”

少年低下头，停了一会儿。

“还有一件事……”

守正正要叫人拿账，听见这句话，手停在半空。

“说吧。”

“家里往后，想歇些日子。”

“歇着？”

“父亲病着，送不了。小人年纪小，做不好。”

清吉说得很快，像是已经背过许多遍。

“昨日送来的炭也不好。母亲说，不敢再误宫里用度，求准换一家。”

廊下安静下来。

守正看了眼那只旧布包。

他昨夜想过许多事：两本账对不上怎么办，森田仍说钱不归自己管怎么办。唯独没想过，孩子来了，先说的是不想再送炭。

“是怕有人为难你们？”

清吉摇头。

“你照实说。”

少年又摇了一次，手指把布角拧得更紧。

守正心里有些急。他特意没有叫森田来，这里没有昨日打人的竹板，连藤井都退到了几步之外。

“没有人催你。”

说完，他自己先听出了不对。

孩子从进来便一直在看他。自己每问一句，对方就立刻答一句，答得稍慢，额角便绷起来。

守正收回手。

“刚才问得急了。你先喝水。”

清吉捧起杯子，却没有喝。

清吉捧紧杯子，指背上的红痂被绷开。他吸了口气，又抬眼看看守正，像怕人嫌他喝得慢。守正看见了，已经到了嘴边的话又收了回去。

过了好一会儿，他才说：

“家里没有本钱了。”

“昨日不是先给了一笔？”

“要抓药，还要还人家的。”

“还谁的？”

“进炭时借的。”

守正看着他，没再追问。

清吉的声音低了些，却渐渐连起来了。

昨日他回去以后，母亲把钱摊在席上，一份一份分开。父亲看着，叫她留一点，好接着进炭。她算了几次，仍不够，又去问炭行能否赊些。人家说，上回的钱还没还齐，要先结清。

“母亲找了别的买主，肯先付一笔。昨日给了，才进到炭。说送到了，就把余下的结清。”

清吉抬起头。

“那边今日午后要。母亲一个人送不动。”

守正忽然想起昨天的回话。

她问孩子几时能回去。

他当时听过，点了头，甚至没有多想。

“所以，今日急着回去？”

清吉点头。

“父亲说，御前既然召，就得来。账带来，问什么答什么，家里的事不许多嘴。”

少年说到这里，声音又低下去。

“可母亲叫小人问明白。昨日领了那笔钱，往后是不是还得照常送？”

守正望着他。

“有人这样吩咐过？”

“没有。”

“那为什么这样想？”

清吉不说话了。

过了一会儿，他向案上那两张纸看了一眼。

守正顺着他的目光看过去。

自己的亲笔和藤井的抄件放在一起。昨日他费了许多工夫，要让上面的每一个字都照原样送到。

如今人坐在面前，仍有许多话，纸上并没有写。

中山忠能来的时候，清吉已经将账摊开。

老人听青木说了缘由，先看了一眼天色。

“问过便让他回去吧。既无力供应，另择一家也是常事。”

守正转向清吉。

“昨日给你的，是已经送来那些炭的钱。以后送不送，另说。”

清吉的肩膀松了一点。

“那余下的……”

话说到一半，他又咽了回去。

中山忠能接道：

“旧账仍照旧账查核。不会因你家歇业就一笔抹去。”

清吉俯下身，额头几乎碰到了垫子。

守正等他重新坐直，才将宫里的账推过去。

“先对这三回。对完你就走。账本也带回去。”

中山忠能在一旁坐下，叫人请森田来。

两本账并排铺着。清吉家的封皮磨穿了一角，里面夹着一截细麻绳。少年认字不多，遇到念不出来的地方，便指给藤井看。

他认得父亲画的记号：斜划是已经送走的，旁边的小圈，是回来后才添上的。

“这个圈呢？”守正问。

“钱收到了。”

清吉指着最后几行。

三处斜划，只有最前面的一处，旁边添着一个小圈。

圈画得很重，笔尖将纸戳破了一个小洞。

那是昨夜添的。

森田到了，俯身看了两遍。几笔数目对下来，竟没有差。

守正抬眼看他。

森田仍低着头，脸上看不出得意，也没有惊慌。他将两本账的页角挪齐，按住清吉家那本快散开的线脚，等藤井记完才松手。

这账他知道，清吉的父亲也知道。两边各记了一本，清清楚楚地欠着。

中山忠能让藤井将剩余两笔另记下来。

“先查可从何处支取。”

守正本想问几时能付，话到嘴边，改成了：

“查到以后，把日子也回给这家人。若还付不出，也让他们知道。”

中山忠能看了他一眼，慢慢点头。

清吉将旧账收回布里。系绳时，他的手比方才快了许多。

守正看着他起身，想起还有一件事。

“昨日让你问的米价，问过没有？”

少年停住。

“问过了。”

“去年一袋多少？如今呢？”

清吉看了看中山忠能，又看向守正。

“母亲说，不知道。”

“平日不去买米？”

“去。”

“那怎么不知道？”

清吉摸着布包上的绳结，声音很轻。

“我们家，早不整袋买了。”

守正手边还放着一张空纸，原想记下两个价钱。

他看了那张纸一会儿，将它搁到旁边。

“今日要买多少？”

“要看午后那担炭，能卖到多少钱。”

院子里响起报时的声音。

清吉朝外面望去，手指已抓住了布包。

“去吧。”守正说。

少年行过礼，跟着青木出了门。到了廊下，脚步便快起来。

守正没有再叫住他。

案上的纸摊着。昨日那张召人的抄件，底下多了一行小字：已经传到，来日携账。

这件事，已经办完了。

他又拿过记着两笔欠款的纸。

“外祖父，”他抬起头，“能从哪里找出这笔钱？”
