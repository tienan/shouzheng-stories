ABOUT THE STORIES

守正是谁

守正是这个系列的原创主人公。他三十二岁，在制造企业担任基层生产主管，长期阅读《毛选》，关心普通劳动者的处境，也相信普通人能够参与并改变共同事务。

他的经验来自车间、个人阅读和工作中的受挫。他会判断失误，也会被自己习惯使用的权力吸引。到了一个陌生时代，他仍须听取别人的经历，才能知道自己遗漏了什么。

当前连载：《明治未明》

故事从1867年的京都御所开始。守正醒来，成了少年天皇睦仁。他对未来的认识只是历史的大轮廓，对眼前的宫廷、藩政与社会仍须重新了解。

一个送炭的孩子，把他带进了第一件需要处理的事。此后的故事，将从人物对话、具体事件和每次选择的后果中逐步展开。

本作为架空历史小说，包含原创人物、虚构对话与情节。

关于阅读与更新

小说按节连载，每节约三千字。新读者可以从引言读起，已读的章节始终保留在目录中。也可以通过 RSS 订阅更新。

字号、纸色与阅读位置保存在当前浏览器中。更换浏览器或清除本机数据后，这些偏好不会同步保留。

关于创作

小说与视觉素材的制作使用了人工智能工具。故事设定、人物选择及修订随连载持续发展。
