故事里的人 / SHOUZHENG

守正，仍在学习。

三十二岁，制造企业的基层主管。别人答得慢，他容易着急；轮到写停工说明，却改了三遍，还在犹豫要不要写上采购部经理的名字。

到了京都御所，他还是想尽快把事情办好。可送炭的孩子有自己的难处，也有比回答他的问题更着急的事。
